Horo is a free Mac menu bar timer. Click it, type how long you want, press Return, and the timer runs. There are no dials or fields.

Speed is the whole point of the design. If setting a timer takes ten seconds, you skip it, and the work runs on without a boundary.

Type plain phrases:

```
45m #writing
1.5hr
60s
@12pm
```

The first is a 45-minute timer labelled with a project tag. The next two are durations. The last counts down to a clock time. You can run several timers at once and see them all in the Timer List window.

Use it to time-box anything open-ended, such as email or a tidy-up. Type `20m #inbox` before starting and let the timer end it. Try `25m` for a Pomodoro block.

Install it from the link, then start a timer today on the next task that has no end.
