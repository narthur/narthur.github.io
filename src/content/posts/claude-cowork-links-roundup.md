Claude just [introduced Cowork](https://claude.com/blog/cowork-research-preview?utm_source=substack&utm_medium=email)—a new piece of software for using Claude to help with projects other than programming. From the article:

> How is using Cowork different from a regular conversation? In Cowork, you give Claude access to a folder of your choosing on your computer. Claude can then read, edit, or create files in that folder. It can, for example, re-organize your downloads by sorting and renaming each file, create a new spreadsheet with a list of expenses from a pile of screenshots, or produce a first draft of a report from your scattered notes.

I’ve already been working this way for a long time. The workflow:

1.  Navigate to a project folder inside [Warp](https://www.warp.dev/).
2.  Talk to Warp’s AI, allowing it to create, update, and reference project notes as needed.
3.  Warp asks questions, suggests next steps, searches the internet, etc.

That’s it.

I’ve found it to be a super powerful way to work on ambiguous and overwhelming projects. I create a [Beeminder](https://www.beeminder.com/) goal for spending time on the project, and then plans, research, and task lists develop over time with ease.

It seems like the main advantages Cowork may have over just using something like Warp for this is Cowork’s ability to create files in more document formats and use connectors to other services. I’m not sold that those are big enough benefits for me personally to switch.
