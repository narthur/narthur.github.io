## Accessibility

The rebuild shipped with an accessibility backlog too large to clear in one pass, which is why I built [Pa11y Ratchet](https://github.com/marketplace/actions/pa11y-ratchet). The CI action only fails on an increase in the number of accessibility issues, allowing a team to whittle an existing backlog down over time.
